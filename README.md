# WMT Enhanced

Улучшения [оригинального инструментария iEzhuk и Zealot111](https://github.com/iEzhuk/WMT_MapTools) для создания удобных TvT- (и PvE-) миссий от Snowkinger.

### Новые функции в сравнении с базовым WMT на данный момент:
  - Добавлена возможность изменить бинды мода через настройки управления CBA (настройки > управление > настроить дополнения).
  - Добавлена возможность принудительно ограничить минимальный порог параметра "Ландшафт" (отвечающего за прорисовку травы в том числе) через модуль Main.
