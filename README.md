# WMT Enhanced

[English](README.md) | [Русский](README.ru.md)

Enhancements of [original instrument from iEzhuk and Zealot111](https://github.com/iEzhuk/WMT_MapTools) for convinient TvT- (and PvE-) missions creation by Snowkinger.

### New functions in comparison with basic WMT
- Added ability to change mod's binds through CBA controls settings (settings > controls > configure addons).
- Added ability to force minimum "Terrain" parameter value through Main module.

### Authors
- Original WMT instrument: iEzhuk и Zealot111
- Enhanced: Snowkinger
